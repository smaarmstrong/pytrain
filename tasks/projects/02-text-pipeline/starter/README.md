# hashtag report pipeline — scaffold

`report.py` is the graded entry point (`python report.py NOTES_DIR [--top N]`).
`extract.py` is a suggested home for the regex extraction layer; how you split
the code is up to you.

`notes/` holds two sample files matching the acceptance example in the prompt
— handy for eyeballing your output while you work. The grader uses its own
fixture directories.
