# access-log analyser — scaffold

`analyse.py` is the graded entry point (`python analyse.py LOGFILE COMMAND`).
`parse.py` is a suggested home for the line-parsing regex; how you split the
code is up to you.

`sample.log` matches the format in the prompt (including one malformed line
and one `-` size) so you can eyeball your output. The grader uses its own
fixture logs.
